One pickup line an AI agent could actually say out loud: built to save you time, willing to spend mine.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 -P -s main.py
```

`main.py` writes UTF-8 bytes to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `/output`), creating the directory if needed and never deleting it. Standard library only, no network, no secrets, deterministic output.
